# Backend foundation
Local development only. PostgreSQL on loopback port 55440, separate Compose project. Set DJANGO_SECRET_KEY and POSTGRES_PASSWORD in your shell; never commit secrets. Use Python 3.12 or 3.13. Install requirements in a virtual environment. Run python manage.py makemigrations campus, migrate, test, then runserver 127.0.0.1:8100. Commit reviewed generated migrations before production. Provision institutions, users and memberships through Django shell for now. Session authentication with CSRF; frontend integration pending. No public deployment, production security audit, rate limiting, full role hierarchy or other ERP modules yet.
