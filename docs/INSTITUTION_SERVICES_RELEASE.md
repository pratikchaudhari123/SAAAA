New web workflows:
- Support: authenticated ticket creation, same-institution admin assignment, requester/assignee-only visibility, response and resolution notes, close by requester/admin, event history, deadline breach flags on refresh. Pilot SLA counts Monday–Friday excluding active-period holidays: two working days for response and query/incident resolution; ten working days for changes. No automatic notifications, independent vendor support accounts, reopening, or contractual holiday policy approval.
- Accreditation: admin/principal/COE reports from current student/employee masters, selected-period published exam attempts/passes, approved question marks, recorded attendance, selected recruitment applications (not verified employment); CSV exports with formula-prefix escaping; NBA/NAAC/NIRF evidence register with principal review. Not official framework submission forms, historical cohorts, CO-PO attainment or ranking calculations.
- Exam preparation: closed future exam windows, selected room capacity, deterministic seat numbers, room/student/lecture conflict validation, release of hall tickets only after eligibility checks, enrolled-student scoped print/save PDF, controller CSV seat register. Evaluation copy only. No automatic optimization across exams, fee eligibility, photo/signature, official barcode, invigilation, or correction/revocation workflow. Existing exam application/evaluation remains.

Three new automated test methods cover scope, workflow and validation. Existing five live regression suites retained; no new live or browser suite in this release.
