New: custom institutional roles with immutable parent hierarchy, clone of effective capabilities, multiple concurrent additive grants for internal staff, scheduled starts and optional expiry, explicit admin revocation and audit. Capabilities are enforced server-side on document issuance, reporting and finance/hostel/academic/library clearance. Admin-only role configuration. External and student accounts cannot receive staff grants. Built-in permissions remain; revoking a custom grant does not remove existing default permissions. No universal role engine, department scope, deny precedence, automated designation assignment, field encryption or legacy API migration yet.

Documents: configurable version-coded text templates, original/duplicate policies, personal online application, pending/issued/rejected/revoked states, required departmental clearance and recheck of recorded fee balance and hostel allocation when relevant, authorized review with reference, immutable issuance snapshot and unique serial, student print/save PDF using browser. Five evaluation document types: bonafide, character, fee statement, clearance and basic student ID. Character content requires real authorized verification; no independently verified character or official signature is implied. Fee statements are restricted to issued document viewers and authorized issuers; report-only users see metadata. No native downloadable generated PDF, legally valid signature, QR/public authenticity check, photographic ID layout, certificate version retirement, period-based repeat originals, transfer/migration/degree/transcript, student leave/activity permissions or full dues subledger. Revocation cannot recall previously printed copies. The output is explicitly marked evaluation copy. No real data.
