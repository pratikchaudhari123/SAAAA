# Historical data mapping and NEP credit recognition
Student CSV import now accepts explicit source-to-target column mapping, permits extra ignored fields, validates distinct headers, previews normalized data and binds apply to the normalized digest. Existing IDs remain unchanged and new students enter Pending. This does not migrate historical finance, exam, attendance, employee, documents or prior academic years. Source formats and reconciliation require authorized sample exports.
Credit recognition: active student applies for external credits mapped to an existing course in the same program; principal verifies reference and approves/rejects; duplicate source reference per student and credit ceiling per mapped course enforced. Internal register only; no external ABC/APAAR connection, verified external identity, automatic credit redemption, course exemption, graduation, multi-entry/exit or NEP compliance claim.
